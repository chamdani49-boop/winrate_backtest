📖 Panduan Lengkap
Cara pakai TVBT Pro dari awal sampai selesai
Alur Kerja
1

Setup Indikator

Isi nama indikator, pair, timeframe, dan periode backtest di menu Setup Indikator.

2

Ambil Histori Signal dari Telegram

Buka Telegram Desktop → klik nama group → ⋮ → Export Chat History → format Plain Text → Export. Dapat file messages.txt.

💡 Atau Ctrl+F di group → cari "BUY"/"SELL" → copy manual semua pesan signal
3

Parse di Telegram Parser

Buka menu Telegram Parser → paste teks histori signal → pilih format → klik Parse. Tool otomatis ekstrak entry, TP, SL dari berbagai format.

⚠️ Jangan skip signal yang loss! Banyak admin grup diam saat SL kena. Verifikasi sendiri di chart TradingView.
4

Pindah ke Signal / Import CSV

Klik tombol "📥 Pindah ke Signal" setelah parse selesai — atau export CSV lalu import di menu Input Signal.

Cek kolom EXIT — isi harga aktual (TP atau SL yang kena) untuk setiap trade yang sudah closed.
5

Lihat Hasil Backtest

Buka Hasil Backtest — lihat winrate, profit factor, equity curve, streak, dan statistik lengkap.

6

Kalkulasi Modal

Buka Kalkulator Modal → input modal Rp-mu → proyeksi hasil nyata berdasarkan statistik backtest.

Format Signal yang Dikenali
FORMAT BLOK
🟢 BUY BTCUSDT Entry: 95,000 TP1: 97,000 SL: 94,000
FORMAT INLINE
BUY BTCUSDT entry 95000 tp 97000 sl 94000
DENGAN TANGGAL
[15/01/2024] SELL EURUSD Entry: 1.0850 TP: 1.0790 | SL: 1.0880
Penjelasan Metrik
WINRATE — % trade profit dari total closed
PROFIT FACTOR — Total profit ÷ total loss. >1.5 bagus, >2 sangat bagus
EXPECTANCY — Rata-rata profit per trade (dalam R)
SHARPE — Return ÷ volatilitas. >1 layak, >2 excellent
MAX DD EST — Estimasi penurunan equity terburuk
STREAK — Win/loss berturut-turut terpanjang
Tips Backtest Valid
✅ Minimal 30 signal untuk valid secara statistik
✅ Backtest di berbagai kondisi market
✅ Winrate >55% dengan RR 1:2 sudah sangat baik
✅ Max drawdown di bawah 20% masih aman
Deploy Tool Ini Secara Gratis
GitHub Pages — Upload sebagai index.html → Settings → Pages → aktifkan. URL: username.github.io/nama-repo
Netlify Drop — Drag & drop file ke netlify.com/drop. Selesai dalam 30 detik tanpa akun.
Vercel — Hubungkan repo GitHub → auto deploy setiap update.
